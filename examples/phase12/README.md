# Phase 12 read-only examples

Both examples carry the same two real source records through different header schemas. `External Row ID` is a source locator, not an official material code. `Material Code` is intentionally blank because the inspected corpus supplies no confirmed CPSE material code. Blank technical fields remain unknown. The extra note column demonstrates raw-field retention and unmapped-column reporting.

Use the header-only templates for integration design. Preview and adapter commands never write to SAP/ERP.
